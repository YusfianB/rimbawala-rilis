# Rimbawala — rilis APK

Aplikasi Android untuk pendaki, trail runner, dan traveler: dari persiapan sampai pulang, tetap berfungsi tanpa sinyal.

Repo ini hanya berisi **berkas rilis** (APK), katalog peta, dan halaman privasi. Kode sumbernya ada di repo privat terpisah.

## Memasang

1. Buka halaman [Releases](../../releases), unduh file `.apk` terbaru.
2. Saat Android bertanya, izinkan **Instal aplikasi tidak dikenal** untuk browser atau pengelola file.
3. Bila Play Protect memberi peringatan, pilih **Tetap instal**. Wajar untuk APK di luar Play Store.
4. Versi baru cukup dipasang menimpa versi lama. Data tidak hilang.

APK ditandatangani kunci yang sama setiap rilis, jadi pembaruan bisa menimpa versi sebelumnya.

Aplikasi tidak punya server, tidak memakai analitik, iklan, atau pelaporan crash. Semua data tersimpan di HP pengguna. Rincian: [privasi.html](privasi.html).
